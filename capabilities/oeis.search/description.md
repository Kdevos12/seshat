Searches the On-Line Encyclopedia of Integer Sequences (oeis.org). Give the consecutive `terms` of a sequence, or the number `id` of one (such as A000045), one of the two. It returns how many sequences the site says match (`count`) and the first page of them (`results`): the number, the name, the `offset` (the index of the first term), the terms the site shows as decimal text, and the keywords. A match is a lookup and no proof: it suggests a formula to conjecture, and only a Lean proof settles it. The site is a public one: calls are spaced out, and the same request is sent to it only once.
