Runs SageMath code and returns the value of its last line and what it printed. The code is Python with Sage's syntax: `^` is a power, `1/3` is a rational, `K.<a> = NumberField(x^3 - 2)` names a generator. Variables and functions stay defined from one call to the next within this session, and each session starts empty. A name the session has not assigned is refused ("not a name this server offers"), except a letter with an optional index (`w`, `k1`, `x_2`) or the name of a Greek letter, which becomes a symbolic variable: `G.order()` then fails, sometimes with an empty message. So give what you keep a name of two letters or more, such as `petersen = graphs.PetersenGraph()`. Sage brings PARI and FLINT (number theory), GAP's groups with the small groups library (`SmallPermutationGroup(n, k)`), nauty (`graphs(n)`, `graphs.nauty_geng`), Singular (polynomial rings), Maxima (symbolic calculus), a SAT solver (`SAT()`) and linear programming (`MixedIntegerLinearProgram`). Errors come back with Python's message. Imports, files and the network are refused.
