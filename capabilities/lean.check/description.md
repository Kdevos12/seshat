Elaborates whole Lean files in a REPL running the pinned Lean and Mathlib. For each file it returns Lean's messages (severity, position, text), the `sorry`s left with their goals, and a status: `valid` (no error and no `sorry`), `sorry`, `lean_error`, `repl_error`, `timeout` or `server_error`. Positions are those of the file as sent: line 1 is its first line. A `valid` result is a fast check, not a certificate: code that runs during elaboration can print any message, so a proof is trusted only once the certifier has replayed it through the kernel.
