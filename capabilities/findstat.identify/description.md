Asks FindStat (findstat.org), the database of combinatorial statistics, which statistics take the values you computed. Give a `collection` (FindStat's name for the objects: `Permutations`, `Dyck paths`, `Graphs`...) and `data`: objects of that collection, each with the `value` you computed on it. It returns the statistics whose values agree, by St number and name. The notation of the objects is FindStat's (a permutation is a list such as `[2, 1, 3]`). Agreement on the objects you gave is evidence of a statistic and no proof of one: more objects make it stronger, and only a Lean proof settles a statement. The site is a public one: calls are spaced out, and the same request is sent to it only once.
