Searches for a proof one tactic at a time, on Lean's goal states, and returns the tactics that closed the goal. At each state it tries the tactics you propose, in your order, and the battery's tactics for the goal's domain; a tactic Lean accepts that changes the goals makes a new state. States are tried best first by the sum of the log rank scores along the path divided by depth to the power alpha; the budget is in tactics tried. The result is a list of tactics, each acting on the first goal: put them one per line after `by` in your file and check it with lean_check. It proves nothing for the harness. Whether it beats whole-proof sessions at equal dollars is measured, and the tool is removed if it loses.
