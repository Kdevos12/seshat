Runs Python 3.14 code and returns the value of its last line and what it printed. The interpreter is Pyodide, Python compiled to WebAssembly, with numpy, scipy, sympy (exact and symbolic algebra, Gröbner bases with `groebner`), networkx (graphs), mpmath (arbitrary precision), python-sat (`from pysat.solvers import Solver`), highspy (linear and mixed-integer programming), clarabel (conic and semidefinite programming) and gmpy2 (fast big integers); `import` them as usual, and a module outside this set is not available. Integers are exact and `/` between integers gives a float: use `fractions.Fraction` or sympy's `Rational` for exact rationals. Variables and functions stay defined from one call to the next within this session, and each session starts empty. Files can be written and read only in the working directory; the network and JavaScript (`js`, `pyodide.ffi`) are not available.
