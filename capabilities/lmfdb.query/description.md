Reads the L-functions and Modular Forms Database (lmfdb.org) through its API. Give a `collection` (such as `nf_fields`, the number fields) and the `fields` to match, columns of that collection with their values (`{"degree": 2, "disc_abs": 5}`), and it returns the first `limit` records (10 when not given), as the site gives them. The columns are the collection's own; a name the site does not have is an error. A record is data from a database: it gives examples and invariants to conjecture from, and no proof. The site is a public one: calls are spaced out, and the same request is sent to it only once.
