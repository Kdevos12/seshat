# Seshat's logo

A big cat holding a small cat who holds π, with a heart: drawn by Kyllian de Vos, the author of Seshat.

| File | What it is | Where it is used |
|---|---|---|
| `seshat-original.jpg` | the drawing as made | the source of the trace |
| `seshat.svg` | the vector trace, black lines, transparent background | the README (light theme), the documentation's home, every figure's corner (`packages/figures/src/logo.ts`), the local interface |
| `seshat-dark.svg` | the same with light lines, for dark backgrounds | the README (dark theme), the interface's dark theme |
| `seshat-512.png`, `seshat-256.png`, `seshat-64.png` | renders with a transparent background | avatars, slides, the favicon |
